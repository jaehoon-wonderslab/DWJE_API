# 공정·제품 기간 집계 API — 연동 피드백

2026-09-07 재검증 완료. 요청 터미널: `term_68b6d890-b11e-4b17-9256-7271cf6bac59`.

기존 구현이 localhost:8080에서 정상 동작한다. 이번 재개 작업에서는 관련 테스트와 실 API를 다시 검증하고 누락된 최종 피드백을 작성했다.

## 요청

`GET /api/v1/dashboard/process/period`

- 필수: `from`, `to` (`YYYY-MM-DD`). 양 끝 날짜 포함, 두 날짜 간격 최대 92일(최대 93개 일별 버킷).
- `unit`: `day`, `week`, `month`.
- 선택: `processId`, `productCodes`. 제품 코드는 반복 파라미터와 쉼표 구분 모두 지원하며 공백·중복을 제거한다.
- 인증 및 `DASH_PROC` 메뉴 권한을 적용한다.

## 응답 data

| 필드 | 내용 |
|---|---|
| `summary` | 선택 기간·공정·제품 전체 합계 |
| `periods` | 기간 버킷별 지표, `period` 포함 |
| `products` | 제품별 지표, `code`, `productNm` 포함 |
| `processes` | 공정별 지표, `processId`, `process` 포함. 제품 필터는 적용하되 선택 공정과 무관하게 비교 |

공통 지표는 `qty`, `okQty`, `ngQty`, `defectRate`, `yieldRate`다. 비율은 합계 수량으로 계산한 퍼센트 값이며 소수점 두 자리 반올림이다.

`period`는 day 해당 일자, week 월요일, month 월초의 `YYYY-MM-DD`다. 경계 버킷도 요청 날짜 범위 안의 자료만 집계한다.

빈 버킷은 수량 0·비율 null이다. 원천 그룹 전체가 미수집인 수량은 null을 유지한다. 수량 권한이 없으면 세 수량이, 수율 권한이 없으면 두 비율이 모든 응답 구역에서 null이다. null을 0으로 치환하지 않는다.

전체 요약에는 제품 미매핑 자료도 포함하지만 products는 제품 코드가 있는 그룹만 반환한다. 또한 그룹별 미수집 수량으로 qty가 null일 수 있으므로 제품 qty의 단순 합이 summary.qty와 같다고 가정하지 않는다.

잘못된 날짜·단위·역전·기간 초과는 400, 없는 공정은 404, 미인증은 401이다.
